🚀 使用方法

  1. 两台手机都装好 secret base 和 EasyTier
  2. 打开 EasyTier：一台「创建网络」，另一台扫码或输入配置加入，两台都打开开关直到「已连接」
  3. 打开 secret base：一方选「等待对方」，把 10.144 开头的地址和匹配码发给对方；另一方选「连入对方」填入
  4. 核对双方屏幕上的 6 位校验码一致，开始聊天
